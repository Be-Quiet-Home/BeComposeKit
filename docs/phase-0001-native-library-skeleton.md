# Phase 0001 — Native Library Skeleton

## Goal

Create the smallest possible buildable BeComposeKit library skeleton.

This phase does not introduce application composition features yet.

## Included

- public umbrella header
- version function
- static library build
- smoke test

## Excluded

- command system
- window shell
- layout recipes
- preferences
- job runner
- app scaffolding
- Kit Composer tooling

## Reason

Before BeComposeKit grows bricks, the repository needs a clean, testable native build foundation.
